# Prode Mundial 2026

Aplicacion web para organizar un Prode del Mundial 2026 entre participantes invitados.

## Acceso

Sitio publicado:

https://prode-mundial-2026-3e643.web.app

## Manual para participantes

El instructivo de uso esta en:

[MANUAL_USUARIO.md](./MANUAL_USUARIO.md)

## Desarrollo

```bash
npm install
npm run dev
```

## Validacion

```bash
npm run lint
npm run build
```

## Deploy

```bash
firebase deploy --only hosting
```
